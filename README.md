# 平阳新纪元学校夏季运动会管理系统 - 介绍与使用提示

## 一、软件介绍

### 1.1 软件简介
平阳新纪元学校夏季运动会管理系统是一款专为学校运动会场景设计的桌面端成绩管理工具，基于 Python + PyQt6 框架开发，支持 **MySQL** 和 **SQLite** 双数据库模式：
- 优先使用 MySQL 数据库（适合多用户、网络环境）
- MySQL 不可用时自动降级为 SQLite 本地数据库（开箱即用，无需额外配置）

系统支持多角色用户权限管理，可满足运动会期间不同岗位的工作需求，帮助学校高效完成班级排名统计、运动员项目成绩管理、数据查询筛选等工作，提升运动会的组织管理效率。

### 1.2 主要功能
- **用户账号管理**：支持班主任、裁判两种角色的用户注册，登录验证机制保障数据安全
- **多角色权限适配**：不同角色登录后自动进入对应功能界面，总控管理员可进行全局数据管理，班主任可管理班级相关数据，裁判可完成成绩录入工作
- **班级排名展示**：分七年级、八年级、九年级三个维度，直观展示各班级的运动会排名情况
- **运动成绩查询**：支持按运动项目筛选，快速查看对应项目下所有运动员的成绩信息，支持数据实时刷新
- **双数据库自动切换**：优先连接 MySQL，连接失败自动降级为 SQLite，确保系统随时可用

## 二、环境准备

在运行软件之前，需要先准备好运行环境：

1. **系统要求**：支持 Windows、macOS、Linux 全平台运行
2. **Python 环境**：需要安装 Python 3.6 及以上版本（可从 Python 官网下载安装）
3. **数据库**：
   - **推荐（可选）**：安装 MySQL 数据库服务，创建名为 `新纪元` 的数据库，适合多用户协作场景
   - **开箱即用**：不安装 MySQL 也可以，系统会自动使用内置的 SQLite 数据库
4. **依赖包安装**：
   软件依赖 PyQt6、pyinstaller 等工具包，你可以通过以下命令一键安装：
   ```
   pip install -r requirements.txt
   ```
   也可以手动执行以下命令安装：
   ```
   pip install PyQt6 pyinstaller
   ```
   > 如需使用 MySQL，还需额外安装 pymysql：
   > ```
   > pip install pymysql
   > ```

## 三、软件运行方式

### 3.1 源码直接运行
安装好依赖后，直接运行主程序文件即可启动软件：
```
python main.py
```
启动后会自动初始化数据库，进入软件的欢迎界面。

> **数据库说明**：
> - 如果安装了 MySQL 且配置正确，系统会自动使用 MySQL
> - 如果没有 MySQL 或连接失败，系统会自动使用 `SQL/sport.db` SQLite 数据库文件
> - SQLite 数据库文件会自动创建，无需手动配置

### 3.2 打包为 EXE 可执行文件
如果你需要在没有 Python 环境的 Windows 电脑上运行软件，可以将源码打包为独立的 EXE 可执行文件：

1. 确保已经安装了 pyinstaller（已包含在 requirements.txt 中）
2. 运行打包脚本：
   ```
   python exe打包.py
   ```
3. 打包完成后，会在当前目录生成 dist 文件夹，里面的 `平阳新纪元学校夏季运动会管理系统.exe` 就是打包好的程序，直接双击即可运行，无需额外环境。

> 注意：打包过程中会自动处理资源文件，首次运行 EXE 程序时，软件会自动创建 SQLite 数据库文件。

## 四、使用步骤

### 4.1 账号注册与登录
1. 启动软件后，首先进入欢迎界面，你可以选择注册新账号，或者使用已有账号登录
2. **注册新用户**：
   - 点击 "注册" 按钮，进入注册界面
   - 输入用户名、登录密码
   - 选择你的职业（班主任 / 裁判）
   - 如果你是班主任，可以填写对应的班级信息（非必填）
   - 点击 "注册" 按钮完成注册，注册成功后会自动进入主界面
3. **登录已有账号**：
   - 点击 "登录" 按钮，进入登录界面
   - 输入你的用户名和密码
   - 点击 "登录" 按钮，验证通过后即可进入主界面
   - 如果提示 "用户或密码错误"，请检查输入的信息是否正确

> **默认管理员账号**：用户名 `1949`，密码 `1001`（总控管理员权限）

### 4.2 主界面功能说明
登录成功后，你会进入软件的主界面，包含两个功能标签页：

1. **班级排名**
   - 该页面分三个区域，分别展示七年级、八年级、九年级的班级排名数据，直观呈现各年级的班级积分 / 排名情况

2. **运动成绩**
   - 你可以通过右上角的 "运动项目" 下拉框，选择不同的运动项目
   - 选择后页面会自动筛选出该项目下所有运动员的成绩信息
   - 点击页面下方的 "刷新" 按钮，可以重新加载最新的成绩数据

### 4.3 角色专属功能
根据你登录的角色不同，系统会自动弹出对应角色的功能窗口：

- **总控管理员**：可进行全局的数据管理、系统配置等操作
- **班主任**：可管理本班的运动员信息、查看班级相关的成绩数据
- **裁判**：可完成对应项目的成绩录入、排名统计等工作

## 五、注意事项

1. **数据备份**：
   - MySQL 模式：所有数据存储在 MySQL 数据库的 `新纪元` 数据库中，请定期备份数据库
   - SQLite 模式：所有数据存储在 `SQL/sport.db` 文件中，请定期备份该文件

2. **数据库配置**：
   - 如需使用 MySQL，请在 `sql.py` 文件中修改数据库连接信息（主机、用户名、密码、数据库名）
   - 不配置 MySQL 也可以正常使用，系统会自动降级为 SQLite 模式

3. **文件路径**：
   - 源码运行时，请不要随意移动 SQL 目录和 images 目录，否则会导致软件找不到数据库和图标资源
   - 运行 EXE 程序时，数据库文件会自动生成在程序的同级目录，请不要删除该目录下的 SQL 文件夹

4. **权限说明**：不同角色的功能权限相互独立，班主任无法修改其他班级的数据，裁判仅可录入负责项目的成绩，保障数据的安全性

5. **数据刷新**：如果其他用户更新了数据，你可以点击主界面的 "刷新" 按钮，重新加载最新的数据

## 六、常见问题

**Q1: 运行 main.py 提示 "ModuleNotFoundError: No module named 'PyQt6'"？**
A: 这是因为没有安装依赖包，请先执行 `pip install -r requirements.txt` 安装所有依赖后再运行。

**Q2: 运行时提示数据库连接失败怎么办？**
A: 系统会自动降级为 SQLite 模式继续运行，不影响使用。如果需要使用 MySQL，请检查 MySQL 服务是否已启动，并确认 `sql.py` 中的数据库配置是否正确。

**Q3: 打包 EXE 的时候提示找不到图标文件？**
A: 请检查当前目录下是否存在 `images\图标.ico` 文件，确保该文件路径正确，否则打包会失败。

**Q4: 忘记登录密码怎么办？**
A: 你可以重新注册一个新的账号使用，或者联系系统管理员在数据库中重置密码。

**Q5: MySQL 和 SQLite 有什么区别？**
A:
- **MySQL**：适合多用户同时使用，数据集中存储，需要安装和配置 MySQL 服务
- **SQLite**：单文件数据库，开箱即用，无需安装任何服务，适合单机使用
- 系统会自动选择可用的数据库，无需手动切换
